# Results

| path | contents |
|---|---|
| `trials_sage_sar_px4mode.csv` | 5 scored runs, `sage_sar` |
| `trials_sage_rescue.csv` | scored runs, `sage_rescue` (main evaluation and demo) |
| `trials_sage_hard.csv` | scored runs, `sage_hard` |
| `summary.md` | table generated by `scripts/make_figures.py` |
| `figures/` | architecture diagram, results chart, LinkedIn card |
| `logs/<run id>/` | planner, mission manager, offboard, energy, localizer and world-model logs of every run |
| `raw/<run id>/` | pose and battery logs and stills of filmed flights (JPEG frames are not stored) |
| `demo/` | stills of the first recorder version |
| `archive/` | earlier configurations and partial batches kept for reference |

CSV columns: `trial, date, world, status, found, tp, fp, fn, mean_err_m, max_err_m, duration_s, rejected_candidates`, then three optional columns
(`flagged, fp_if_flagged_dropped, fn_if_flagged_dropped`) used by the duplicate-flag experiment.
